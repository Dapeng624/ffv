# AI 视频生成工作台 MVP 产品需求文档

> 配套文档：[开发规则文档](./development-rules.md)

## 1. 产品概述

### 1.1 产品名称

暂定名：AI 视频生成工作台

后续可根据品牌方向更名，例如：VidiFlow、AdMotion、VideoCraft、快影工坊、灵感视频台等。

### 1.2 产品定位

一个面向短视频创作者、小商家和小型营销团队的 AI 视频生成工作台，帮助用户通过商品图、人物图、场景图或文本描述，快速生成可发布的短视频广告、内容素材和社媒视频。

### 1.3 核心价值

- 降低视频制作门槛：用户不需要拍摄、剪辑或建模，也能生成商品展示、人物口播、创意短视频。
- 提高内容生产效率：通过模板、预设参数和生成历史，快速批量产出多条视频素材。
- 服务商业转化：重点覆盖电商商品广告、本地商家宣传、短视频内容引流等小 B 场景。
- 控制生成成本：通过积分系统、任务队列和生成失败退款机制，让产品具备商业可持续性。

### 1.4 MVP 目标

第一版目标不是做一个复杂的视频编辑器，而是完成一个清晰闭环：

用户注册登录 -> 上传图片或输入描述 -> 选择模板/模型/比例 -> 提交生成任务 -> 等待生成 -> 预览结果 -> 下载视频 -> 查看历史作品。

## 2. 目标用户

### 2.1 电商商家

典型用户：淘宝、抖音小店、TikTok Shop、Shopify、亚马逊卖家。

主要需求：

- 将商品图变成动态广告视频。
- 快速生成多种风格的商品展示素材。
- 适配 9:16、1:1、16:9 等投放比例。
- 批量测试不同广告创意。

核心场景：

- 上传一张商品图，选择“产品旋转展示”“手持展示”“高级感广告镜头”等模板，生成 5-10 秒短视频。

### 2.2 本地商家

典型用户：餐厅、美甲店、健身房、摄影工作室、教育培训、民宿、线下门店。

主要需求：

- 低成本制作宣传视频。
- 用已有图片快速生成门店、服务、活动视频。
- 用于朋友圈、抖音、小红书、视频号发布。

核心场景：

- 上传门店环境图或服务项目图，选择“探店镜头”“活动宣传”“氛围感推广”等模板，生成短视频。

### 2.3 短视频创作者

典型用户：自媒体博主、内容搬运改编者、AI 内容创作者、虚拟人物运营者。

主要需求：

- 快速制作热视频、角色短片、创意特效视频。
- 用人物图或角色图生成动作、镜头和剧情片段。
- 保留生成历史，方便持续迭代同一主题内容。

核心场景：

- 上传人物图，选择“电影感推进”“人物转身”“街拍走路”“创意变装”等模板，生成社媒短视频。

## 3. MVP 功能范围

### 3.1 用户账户

必须支持：

- 用户注册
- 用户登录
- 用户退出
- 找回密码，MVP 可后置
- 查看账户积分余额

建议登录方式：

- 邮箱 + 密码
- Google 登录，后续可加
- 微信登录，面向国内用户时优先级较高

### 3.2 AI 视频生成

#### 3.2.1 图生视频

用户上传一张图片，输入或选择视频动作描述，生成短视频。

核心字段：

- 上传图片
- Prompt 描述
- 模板
- 视频比例：9:16、1:1、16:9
- 视频时长：5 秒、10 秒
- 模型选择：MVP 可先只开放一个默认模型
- 是否开启 Prompt 优化

生成结果：

- 视频预览
- 下载视频
- 复制任务参数
- 再次生成
- 收藏作品，MVP 可后置

#### 3.2.2 文生视频

用户输入文字描述，系统生成视频。

核心字段：

- Prompt 描述
- 风格选择
- 视频比例
- 视频时长
- 模型选择
- 是否开启 Prompt 优化

MVP 优先级：

图生视频优先于文生视频。小 B 用户通常已经有商品图、门店图、人物图，图生视频更贴近商业需求。

### 3.3 模板库

模板是 MVP 的关键功能。模板能降低用户写 Prompt 的难度，也能让产品看起来更专业。

#### 3.3.1 模板分类

第一版建议包含以下分类：

- 商品广告
- 人物短片
- 门店宣传
- 热门特效
- 社媒内容

#### 3.3.2 推荐模板

MVP 可先内置 12-20 个模板。

商品广告类：

- 产品旋转展示
- 高级感推近镜头
- 手持商品展示
- 桌面产品大片
- 包装盒开场

人物短片类：

- 人物缓慢转身
- 街拍走路
- 电影感推近
- 时尚杂志镜头

门店宣传类：

- 探店推进镜头
- 美食氛围镜头
- 服务项目展示
- 活动促销短片

热门特效类：

- 快速变装
- 环绕运镜
- 动态缩放
- 开场冲击镜头

社媒内容类：

- 小红书风格封面视频
- TikTok 竖屏广告
- Instagram Reels 展示

#### 3.3.3 模板字段

每个模板建议包含：

- 模板名称
- 模板分类
- 模板封面
- 适用对象：商品、人物、门店、通用
- 默认 Prompt
- Prompt 变量
- 默认比例
- 默认时长
- 默认模型
- 消耗积分
- 是否热门

### 3.4 生成任务管理

由于 AI 视频生成耗时较长，必须采用任务机制。

任务状态：

- 等待中
- 生成中
- 生成成功
- 生成失败
- 已退款，适用于消耗积分后失败的任务

用户可查看：

- 当前任务进度
- 任务创建时间
- 使用模板
- 输入图片
- Prompt
- 输出视频
- 消耗积分

### 3.5 我的作品

用户可查看历史生成结果。

基础功能：

- 作品列表
- 按生成时间排序
- 视频预览
- 下载视频
- 再次生成
- 删除作品

后续可加：

- 文件夹/项目
- 收藏
- 批量下载
- 分享链接
- 团队协作

### 3.6 积分系统

视频生成成本较高，MVP 必须有积分系统。

基础规则：

- 新用户注册送免费积分。
- 每次生成前预扣积分。
- 生成成功后确认扣除。
- 生成失败后自动返还积分。
- 不同模型、时长、清晰度消耗不同积分。

示例规则：

- 5 秒普通视频：10 积分
- 10 秒普通视频：20 积分
- 高清生成：额外 10 积分
- 高级模型：按普通模型的 1.5-3 倍计费

### 3.7 价格页

MVP 需要清楚展示套餐。

建议套餐：

- 免费体验：注册送少量积分
- 基础版：适合个人创作者
- 商家版：适合电商和门店
- 专业版：适合高频生成用户

价格页必须说明：

- 每个套餐包含多少积分
- 可生成大约多少条视频
- 是否支持高清视频
- 是否支持商用
- 是否有水印
- 积分有效期

### 3.8 后台管理

MVP 可以做轻量后台，至少支持基本运营。

后台功能：

- 用户列表
- 任务列表
- 生成失败记录
- 积分调整
- 模板管理
- 订单记录，接入支付后需要

## 5. 核心用户流程

### 5.1 图生视频流程

1. 用户进入首页。
2. 上传商品图、人物图或门店图。
3. 选择一个视频模板。
4. 系统自动填入默认 Prompt。
5. 用户可修改 Prompt。
6. 用户选择比例和时长。
7. 系统展示预计消耗积分。
8. 用户点击生成。
9. 系统创建生成任务并预扣积分。
10. 用户等待任务完成。
11. 生成成功后展示视频。
12. 用户下载视频或再次生成。

### 5.2 文生视频流程

1. 用户进入生成器。
2. 切换到文生视频。
3. 输入视频描述。
4. 选择风格、比例和时长。
5. 点击生成。
6. 系统创建任务。
7. 生成完成后展示视频。

### 5.3 模板使用流程

1. 用户进入模板页。
2. 按分类筛选模板。
3. 预览模板效果。
4. 点击使用模板。
5. 跳转到生成器并带入模板参数。
6. 用户上传图片或填写描述。
7. 提交生成。

## 6. 内容与安全规则

MVP 必须具备基础内容审核能力，尤其是面向公开商业服务时。

禁止内容：

- 色情或露骨内容
- 未成年人不当内容
- 暴力血腥内容
- 仇恨、歧视、骚扰内容
- 违法交易内容
- 侵犯他人肖像权、商标权、版权的内容
- 冒充真实公众人物进行误导性宣传

建议机制：

- 上传图片审核
- Prompt 文本审核
- 生成结果异常标记
- 用户举报，后续可加
- 管理员人工处理

## 7. 商业规则

### 7.1 积分扣费

- 用户提交生成任务时预扣积分。
- 任务成功后正式扣除。
- 任务失败后自动退回。
- 用户取消等待中任务时退回积分。
- 生成中任务是否可取消，取决于上游模型 API 是否支持。

### 7.2 水印规则

建议：

- 免费用户生成视频带水印。
- 付费用户可去除水印。
- 商业套餐默认无水印。

### 7.3 商用授权

价格页和用户协议中需要明确：

- 用户上传素材需拥有合法使用权。
- 用户对输入素材负责。
- 平台生成内容的商用范围根据套餐确定。
- 如果调用第三方模型 API，需要遵守对应模型服务商的使用条款。

## 14. 开发建议

第一阶段不要追求完整复刻 Higgsfield 这类成熟产品。更适合的切入点是：

先把“商家上传一张商品图，选择模板，生成一条可下载广告视频”的路径做到足够顺畅。

推荐第一版主线：

- 只接一个稳定的视频模型 API。
- 只支持图生视频。
- 只做 12 个高质量模板。
- 只支持 9:16 和 1:1。
- 只做积分，不急着做复杂会员体系。
- 后台先满足排查任务、补积分、管理模板即可。

只要这个闭环跑通，就可以开始收集真实用户的生成样本、失败原因和付费意愿，再决定是否扩展到视频编辑、多模型、长视频讲解和角色一致性。
