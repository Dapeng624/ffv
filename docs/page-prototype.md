# 映作 MVP 页面原型说明

> 原型地址：本地运行后访问 `http://localhost:3000/`  
> 当前版本：V0.1 可交互高保真原型

## 1. 原型目标

验证“小 B 用户能否在首屏理解并完成上传图片、选择模板、设置参数和提交生成”的核心流程，同时验证参考 Higgsfield 工作台布局是否适合商品广告场景。

## 2. 页面信息架构

```text
全局导航
├── 生成工作台
│   ├── 图片上传
│   ├── Prompt
│   ├── 比例与时长
│   ├── 高级设置
│   └── 媒体预览画布
├── 模板库
│   ├── 分类筛选
│   └── 模板卡片
├── 我的作品
│   └── 处理中 / 成功 / 退款状态
└── 价格
    ├── 体验版
    ├── 商家版
    └── 创作者版
```

## 3. 桌面端原型

首屏采用左侧 350-430px 控制面板、右侧自适应媒体画布。首屏下方依次是模板、作品、价格，不设置传统营销 Hero。

核心路径：

1. 从模板卡片选择商业镜头。
2. 模板自动更新 Prompt 和预览画面。
3. 用户上传自己的图片，替换示例素材。
4. 用户选择比例和时长，预览容器同步变化。
5. 用户可展开高级设置。
6. 提交按钮显示准确积分。
7. 点击提交后显示原型反馈，正式开发时接入任务系统。

## 4. 移动端原型

移动端改为单列，顺序为媒体预览、生成参数、模板、作品、价格。顶部保留品牌和账户入口，页面导航收起。

移动端验收重点：

- 360px 宽度无横向溢出。
- 图片上传、Prompt 和主按钮可用。
- 9:16 预览不挤压后续表单。
- 模板分类可横向滚动。
- 价格卡片改为单列。

## 5. 当前可交互范围

- 上传本地图片并更新预览。
- 修改 Prompt 并显示字符数。
- 切换 9:16、1:1、16:9 画面比例。
- 切换 5 秒和 10 秒并更新积分。
- 展开高级设置。
- 模拟模板镜头播放。
- 选择模板并带入参数。
- 按分类筛选模板。
- 模拟生成按钮反馈。

## 6. 当前不接入的真实能力

- 用户认证
- 云端图片上传
- 视频模型 API
- 任务轮询
- 积分数据库
- 支付
- 视频文件下载

这些能力应在视觉原型评审通过后按开发规则逐步接入。

## 7. 原型评审问题

1. 用户是否能在 10 秒内找到上传图片与生成按钮。
2. “模板优先”的方式是否比直接写 Prompt 更适合目标商家。
3. 深色专业工具风格是否符合预期品牌定位。
4. 荧光黄绿色是否适合长期作为主品牌色。
5. 首发是否确实需要文生视频入口。
6. 商家版每月 500 积分的价格感知是否合理。
