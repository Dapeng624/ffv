# 映作 MVP 页面原型说明

> 本地首页：`http://localhost:3000/`
>
> 核心工作台：`http://localhost:3000/studio`
>
> 当前版本：V0.2 核心功能开发版

## 1. 原型目标

首页用于向短视频创作者、电商商家和本地门店解释产品价值；工作台用于验证从素材上传、参数设置、提交任务到查看生成结果的完整路径。当前视觉参考 Higgsfield 的信息密度、模块顺序和深浅色节奏，但保留独立品牌、中文内容和素材。

## 2. 页面信息架构

```text
营销首页 /
├── 公告与全局导航
├── 主视觉区
├── 技术与产品说明
├── 核心优势
├── 四步使用方法
├── 高级能力
├── 产品数据
├── 应用场景
├── 目标用户
├── 常见问题
└── 最终行动入口与页脚

核心工作台 /studio
├── 生成模式
│   ├── 文生视频
│   ├── 图生视频
│   ├── 首尾帧
│   ├── 动作控制
│   └── 视频重绘
├── 素材上传与参数设置
├── 生成预览
├── 模板库
└── 任务历史
```

## 3. 页面跳转

- 首页导航使用页内锚点跳转到核心特性、使用方法、应用场景和常见问题。
- 首页所有主要行动按钮进入 `/studio`。
- 工作台品牌标识与“首页”导航返回 `/`。
- 工作台“生成、模板、任务”导航分别定位对应模块。

## 4. 响应式规则

桌面端首页使用宽幅图像、分栏说明和多列能力卡片。移动端隐藏中部导航，内容改为单列或双列，并保证主视觉仍展示下一步入口。

工作台桌面端为左侧控制面板和右侧媒体画布；移动端改为预览、参数、模板、任务的单列顺序。

## 5. 当前真实能力

- 图片和视频素材上传。
- 匿名工作区隔离素材与任务。
- 五种生成模式及各自输入校验。
- 比例、时长、镜头运动和运动强度设置。
- 异步任务创建、轮询、进度和历史恢复。
- 模板带入提示词与镜头参数。
- 成功结果预览与下载入口。

## 6. 当前模拟能力

- 视频模型输出由统一模型适配层模拟，尚未调用商业视频模型 API。
- 登录、会员、积分结算和支付暂不接入。
- 首页的数据指标是产品能力说明，不是运营统计。

## 7. 后续模板替换边界

购买 UI 模板后，优先替换 `/` 的导航、视觉样式和营销模块组件。`/studio`、`/api/assets`、`/api/generations`、数据库结构和模型适配层应保持接口稳定，仅按新设计调整表现层。

## 8. 验收重点

1. 用户能从首页任一主要入口进入工作台。
2. 用户能理解五种生成模式的输入差异。
3. 上传素材后可以创建任务，并在刷新后恢复任务历史。
4. 360px 宽度下无横向溢出、文字遮挡或不可操作控件。
5. 首页替换模板时不改变核心 API 与数据结构。
