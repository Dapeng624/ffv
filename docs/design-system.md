# 映作 YINGZO 设计系统

> 版本：V0.1  
> 适用范围：MVP Web 端  
> 关联文档：[MVP PRD](./mvp-prd.md) · [开发规则](./development-rules.md) · [页面原型](./page-prototype.md)

## 1. 品牌定位

“映作”是暂定工作名称。品牌应传达专业、快速、商业可用，而不是强调模型参数或技术炫技。

- 中文名：映作
- 英文识别：YINGZO
- 核心文案：把一张商品图，变成能投放的视频
- 品牌语气：直接、克制、可信、面向结果
- 视觉性格：专业创作工具 + 商业影像质感

## 2. 视觉原则

1. 媒体优先：图片和视频占主要视觉面积，控件服务于结果。
2. 工具感：使用稳定网格、明确边界和紧凑信息密度。
3. 主操作唯一：同一视口只保留一个最高权重的荧光黄绿色按钮。
4. 状态有色：主色用于操作，珊瑚红用于警告，绿色用于成功。
5. 少装饰：不使用无业务意义的光球、渐变背景和大面积插画。

## 3. 颜色系统

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `canvas` | `#111210` | 页面背景 |
| `surface` | `#191A17` | 面板和卡片 |
| `surface-raised` | `#22231F` | 浮层和悬停 |
| `surface-soft` | `#2A2B26` | 选中控件 |
| `border` | `#373832` | 默认边框 |
| `text` | `#F5F6EF` | 主文字 |
| `text-muted` | `#A6A89D` | 次要文字 |
| `text-faint` | `#74776C` | 辅助信息 |
| `acid` | `#D7FF5F` | 主操作和品牌识别 |
| `coral` | `#FF745C` | 警告、失败、录制状态 |
| `success` | `#7EE68B` | 成功和完成状态 |

浅色价格区使用 `#EFEFE7` 背景与 `#171813` 文字，形成阶段转换，但不扩展为整套浅色主题。

## 4. 字体与排版

- 中文：优先系统字体 `PingFang SC`、`Microsoft YaHei`。
- 英文和数字：优先 Arial；品牌确定后可替换为有授权的无衬线字体。
- 页面主标题：24-38px，行高 1.12-1.2。
- 区块标题：23-28px。
- 正文：12-14px，行高 1.6-1.7。
- 控件文字：11-13px。
- 辅助标签：9-10px。
- 字距默认 0；仅英文眉题允许 1.4px 左右正字距。
- 不随视口宽度连续缩放字号。

## 5. 间距与尺寸

- 基础间距单位：4px。
- 常用间距：4、8、12、16、20、24、32、48、64、96px。
- 顶部导航：桌面 68px，移动端 60px。
- 表单控件：40-44px。
- 主按钮：54px。
- 移动触控目标：不小于 44px。
- 页面最大内容宽度：1500px。
- 桌面页边距：24px；移动端：12px。

## 6. 圆角与阴影

- 小圆角：4px，用于标签、图标按钮和输入内部元素。
- 标准圆角：8px，用于面板、卡片、输入框。
- 圆形仅用于头像、状态点、播放按钮和明确的圆形图标操作。
- 主面板阴影：`0 20px 50px rgba(0,0,0,.24)`。
- 模板选中状态优先使用边框，不叠加夸张发光。

## 7. 核心组件

### 顶部导航

包含品牌、生成、模板、我的作品、价格、积分和账户。桌面居中导航，移动端收起页面导航，保留品牌与账户。

### 生成控制面板

字段顺序固定为图片、描述、比例、时长、高级参数和生成按钮。只在一个模型可用时隐藏模型选择器。

### 媒体画布

支持 `9:16`、`1:1`、`16:9` 三种固定比例。画面加载前后容器尺寸不变化。工具栏显示当前比例、时长和清晰度。

### 模板卡片

固定媒体比例、名称、类别、时长和积分。点击卡片带入参数；圆形加号是明确的“使用模板”操作。

### 任务状态

- 等待中：中性灰。
- 生成中：主品牌色。
- 已完成：成功绿。
- 失败或已退款：珊瑚红。

### 价格卡片

采用浅色区带，突出套餐的真实产出数量。推荐套餐使用品牌色背景，但保持 8px 圆角与克制排版。

## 8. 交互状态

每个可交互组件必须包含默认、悬停、聚焦、按下、禁用和加载状态。

- 聚焦：2px 主色描边，外偏移 2px。
- 悬停：背景或边框变化，位移不超过 3px。
- 禁用：降低对比度并移除指针反馈。
- 加载：保持原尺寸，禁止因文案改变导致布局跳动。
- 成功：在操作附近反馈，不能只依赖短暂全局提示。

## 9. 响应式

- `>= 1280px`：生成控制面板与媒体画布双栏。
- `801-1279px`：保持双栏，压缩控制面板和间距。
- `<= 800px`：媒体画布在上，控制面板在下，单栏排列。
- `<= 480px`：比例与时长控件改为纵向区块，模板单列。

移动端保持完整生成闭环，不通过隐藏必要字段换取版面简洁。

## 10. 素材规范

- 模板封面至少 1200px 长边，优先 WebP 或高质量 JPEG。
- 视频预览默认静音，进入可视区后加载。
- 封面不得含第三方商标、无授权人物或水印。
- 商品广告素材需要主体清晰、光线可读、留出运动空间。
- 同一模板的封面与实际生成效果方向必须一致。

## 11. 待确认品牌项

- “映作 / YINGZO”是否作为正式品牌名。
- 中文 Logo 字体及商用授权。
- 主色是否保留 `#D7FF5F`。
- 国内版与海外版是否使用同一品牌识别。
- 正式域名与社交分享地址。
